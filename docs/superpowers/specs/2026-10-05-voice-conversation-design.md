# Голосовой разговор с агентом — дизайн

Дата: 2026-10-05

## Цель

Живой голосовой разговор с ИИ-агентом, как voice mode в Codex: говоришь — агент
слышит без кнопки «отправить», отвечает голосом сразу, его можно перебить голосом
посреди ответа, и он понимает, что его перебили.

Успех: включил режим хоткеем, выбрал агента, разговариваешь; перебивание
обрывает звук мгновенно (< 300 мс) и агент принимает новую реплику.

## Решения

- **Отдельная голосовая сессия**, не открытые терминалы: агент запускается
  программно (SDK / app-server), без ввода в окна. Режим «в открытый терминал» —
  не сейчас.
- **Универсально**: Claude и Codex через общий адаптер.
- **Агент выбирается при каждом включении** в окне плагина.
- **Только чтение** на первом этапе (Claude `plan`, Codex `read-only`). Полные
  права — после обкатки.
- **Включение хоткеем**, в режиме микрофон слушает постоянно.
- **Всё распознавание локально.**

## Архитектура

Новый процесс `agent_voice` (Python 3.12, отдельный venv
`~/.local/share/agent-speak/voice-venv` через `uv` — у системного Python 3.14 нет
надёжных колёс faster-whisper), запускается демоном agent-speak как дочерний на
время разговора — отдельный systemd unit не нужен. Три части:

### Слух

`pw-record` (моно, 16 кГц, s16) с источника по умолчанию → Silero VAD (окна по
32 мс) → накопление фразы → пауза ≥ 700 мс завершает фразу → faster-whisper
`large-v3-turbo`, `language="ru"`, CUDA (fallback CPU `small`) → текст.

Эхоподавление — штатный модуль PipeWire `libpipewire-module-echo-cancel`,
подключается конфигом `~/.config/pipewire/pipewire.conf.d/echo-cancel.conf`
(через omarchy-dotfiles, регистрируется в watch.tsv). Устройства по умолчанию не
меняются: эхо вычитается только из звука, прошедшего через `echo-cancel-sink`,
поэтому демон в голосовом режиме играет туда (`pw-cat --target`), а `agent_voice`
слушает `echo-cancel-source`. Без модуля режим работает, но при старте предупреждает.

### Мозг — адаптер агента

Интерфейс (asyncio):

```python
class Agent:
    async def start(self, cwd: str) -> None
    async def send(self, text: str) -> None      # реплика пользователя
    async def interrupt(self) -> None             # оборвать текущий ход
    def deltas(self) -> AsyncIterator[str]        # поток текста ответа
    async def close(self) -> None
```

- **claude** — `claude-agent-sdk`, `ClaudeSDKClient`,
  `permission_mode="plan"`, `cwd`, добавка к system prompt (ниже). Дельты из
  `StreamEvent` text_delta (`include_partial_messages=True`).
- **codex** — подпроцесс `codex app-server`, JSON-RPC по stdio:
  `initialize` → `thread/start` (`cwd`, `sandbox: read-only`,
  `approvalPolicy: never`, `developerInstructions` — та же добавка) →
  на каждую реплику `turn/start`; дельты — уведомления
  `item/agentMessage/delta`; конец — `turn/completed`; перебивание —
  `turn/interrupt`. Точные поля — по `codex app-server generate-json-schema`
  установленной версии.

Добавка к промпту: «Это голосовой разговор. Отвечай коротко, разговорным
языком, без markdown, списков и кода вслух; код и пути упоминай словами».

Сессия живёт, пока включён режим — контекст разговора сохраняется. Авторизация —
текущая у CLI (подписка), отдельных ключей нет.

### Рот

Дельты режутся на предложения (`.`, `!`, `?`, `…`, перевод строки; минимум ~20
символов, иначе клеится к следующему) и отправляются в демон новой командой
`{"cmd":"voice","text":"..."}`. Демон проигрывает их сразу, по порядку, вне
логики активных окон и очередей; существующие нормализация текста и голос
(голос по умолчанию) применяются.

## Демон agent-speak (Rust)

- `Msg::Voice { text }` — в очередь как новый `Kind::Voice`: играется сразу,
  не отбрасывается фильтрами `say`/статусов.
- `Msg::VoiceStart { agent }` / `Msg::VoiceStop` — демон запускает/гасит
  дочерний `agent-voice --agent <a> --cwd <dir>` и держит состояние голосового
  режима.
- Пока режим включён, озвучка терминальных агентов (хуки) глушится: их тексты не
  ставятся в очередь (финалы не копятся).
- `cwd` — из последнего хука активной сессии, иначе `$HOME`.
- Состояние для `subscribe` расширяется полем
  `voice: off|starting|listening|thinking|speaking` и `voice_agent`.
  `agent-voice` сообщает свою фазу командой `{"cmd":"voice_state","state":...}`.
- `Msg::Stop` во время голосового режима обрывает только звук (как сейчас).
- CLI: `agent-speak voice` — переключатель: если режим выключен, просит плагин
  открыть окно выбора; если включён — `VoiceStop`.

## Перебивание

Машина состояний в `agent-voice`:

```
listening ──фраза──▶ thinking ──первая дельта──▶ speaking ──turn done + звук кончился──▶ listening
     ▲                   │                            │
     └──── речь (VAD) ───┴────────────────────────────┘
           → stop в демон + agent.interrupt(), фраза идёт следующей репликой
```

Начало речи (VAD) в `thinking`/`speaking` сразу шлёт `stop` демону и
`interrupt()` агенту, недоговорённые предложения выбрасываются. Ложные
срабатывания VAD короче 250 мс не считаются речью.

## Выбор агента (плагин)

Хоткей → `agent-speak voice` → окно плагина `predmaxim.agent-speak`, первая
строка «Разговор»: Claude / Codex (во время разговора — «Закончить»), последний выбранный первым и в фокусе, Enter — старт (`voice_start`),
Esc — отмена. Вид — по `~/omarchy-dotfiles/docs/rules.md` §9. Последний выбор
хранится в config.toml (`voice_last_agent`). Индикатор показывает фазу голосового
режима (иконка микрофона вместо обычной). Хоткей — свободная комбинация в
семействе `S` (уточняется при реализации, регистрируется в omarchy-dotfiles).

## Ошибки

- Нет микрофона / модель не загрузилась / адаптер упал (нет авторизации,
  `codex` завершился, SDK исключение) → уведомление «Голос: <причина>», режим
  выключается, без автоперезапуска.
- Пустое распознавание или короче 2 символов — не отправляется.
- Пустой ответ агента — ничего.
- Нет echo-cancel — предупреждение при старте, режим работает.
- Демон перезапустился — дочерний `agent-voice` умирает вместе с ним
  (`PR_SET_PDEATHSIG`/закрытие stdin), режим выключен.

## Тесты

- Python без железа: нарезка дельт на предложения; машина состояний (речь в
  `speaking` → stop + interrupt, недоговорённое выброшено); разбор протокола
  Codex на записанных JSON-строках; фильтр коротких/пустых фраз.
- Rust: `voice` играется сразу; хуки глушатся в голосовом режиме; состояние
  `voice` в `subscribe`; roundtrip новых `Msg`.
- Плагин: `test.js` — порядок вариантов (последний первым).
- Живая проверка: разговор с Claude и с Codex, перебивание посреди ответа — в
  наушниках и через колонки.

## Не входит

- Режим «голос в открытый терминал».
- Полные права агента и голосовые подтверждения.
- Слово-активатор.
- Другие агенты кроме Claude и Codex.
