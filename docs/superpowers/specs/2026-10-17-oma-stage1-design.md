# Ома, этап 1: заместитель и сводка — дизайн

Дата: 2026-10-17

## Зачем

Сейчас голосовой разговор — строка «Разговор» в окне настроек озвучки
(`predmaxim.agent-speak`): отдельная сессия Claude только на чтение в папке
активного окна. Она не знает о других агентах и спрятана «не в том меню».

Пользователь часами работает с несколькими агентами (Claude Code, Codex) в
терминалах. Нужен один **заместитель — «прораб»**: он следит за всеми агентами,
которых запустил пользователь, коротко докладывает их состояние голосом и
текстом и отвечает на личные вопросы. Позже он будет выполнять действия в
системе и передавать указания агентам. Имя — **Ома**.

Два вида обращений:

- **Короткий вопрос** («что это за ошибка», «объясни X») — короткий ответ по
  сути, без воды, одинаковый текстом и голосом. Подробности пользователь
  уточнит сам.
- **Долгая работа** — Ома озвучивает короткие статусы, завершение задач и
  финальные сообщения агентов перед вопросом, слушает пользователя и отвечает,
  то есть идёт диалог.

Ночью пользователь не хочет звука — только текст.

## Этапы проекта

Этот документ — только этап 1. Остальные получат свои описания.

1. **Заместитель и сводка** (этот документ).
2. **Слово активации** «Привет, Ома» — опция в настройках: постоянно слушать
   только эту фразу.
3. **Действия в системе через навыки**: «ответь коллеге в Telegram…», «ответь
   техподдержке письмом и отправь, что просят». Навыки пишутся заранее: как
   работать с программой, как найти человека по имени, как отвечать. Почта —
   своя, omarchy-mail.
4. **Указания агентам** — когда появится возможность. Единственный
   официальный путь — Claude Code channels (research preview): MCP-сервер
   внутри сессии, сессия запускается с флагом
   `--dangerously-load-development-channels`, уже открытые окна без флага
   указаний не получат. Адресат — по фокусу, как сейчас чтение статусов, или
   по проекту, о котором идёт разговор.

## Цели этапа 1

- Орб поверх всех окон: состояние Омы одним взглядом.
- Пузырь у орба: текст всего, что Ома говорит.
- Окно Омы: сводка по агентам и чаты с Омой.
- Личные вопросы голосом (клик по орбу) и текстом (поле в окне).
- «Как дела по проектам?» — сводка по всем агентам; разговор о конкретном
  проекте.
- Постоянный диалог (как сейчас голосовой чат), с перебиванием голосом.
- Тихий режим: ничего вслух, только текст; по расписанию, которое можно
  отключить, и вручную.

## Не входит в этап 1

- Указания агентам — Ома только читает (этап 4).
- Действия в системе и навыки (этап 3).
- Слово активации (этап 2).
- Подагенты: в сводке только сессии, которые запустил пользователь.

## Анти-цели — провал, даже если работает

- Длинные ответы, вода, зачитанные списки.
- Звук при включённом тихом режиме.
- Ома что-то меняет в проектах или куда-то отправляет.
- Окно на весь экран; орб мешает работе (перехватывает клики вне себя, висит
  поверх полноэкранного видео).
- Одно и то же в двух местах: значок озвучки в баре и орб.
- Клик по орбу, а «слушаю» наступает через десятки секунд (холодный whisper).

## Решено с пользователем

### Сценарии

1. **Личный вопрос.** Орб в покое → ЛКМ по орбу → «слушаю» → фраза →
   распознанный текст в пузыре с кнопкой «Отправить» (повторный ЛКМ по орбу
   тоже отправляет) → «думаю» → Ома отвечает голосом, тот же текст в пузыре.
2. **Общая картина.** Пузыри со статусами разных агентов всплывают по ходу
   работы. «Как дела по проектам?» → Ома коротко по каждому агенту: проект,
   что делает, в каком статусе, ждёт ли ответа.
3. **Конкретный проект.** После общей картины пользователь спрашивает про один
   проект; Ома объясняет, что там происходит, отвечает на вопросы по нему.

### Орб

- Кружок в углу экрана, поверх всех окон, **без текста**. Можно перетащить в
  другой угол; место запоминается.
- Состояния — цветом и движением:

  | Состояние | Вид |
  |---|---|
  | покой (диалог выключен) | серый контур |
  | слушаю | «дышит» цветом акцента |
  | думаю | вращается |
  | говорю | зелёный |
  | агент ждёт ответа | жёлтый |
  | тихий режим | луна |

  Цвета — из темы Omarchy (`Color.*`), не захардкоженные.
- **ЛКМ** — сказать фразу (сценарий 1). **ПКМ** — окно Омы.

### Пузырь

- Рядом с орбом. Показывает ответы Омы и статусы агентов (с именем проекта).
- **До трёх пузырей стопкой**: новый снизу, у орба; старые поднимаются выше.
  Самый старый — полупрозрачный, с переходом от непрозрачного края к
  прозрачному. Четвёртый вытесняет самый старый; всё пропущенное остаётся в
  окне.
- В тихом режиме пузыри висят до клика.
- В сценарии 1 сначала показывает распознанную фразу и кнопку «Отправить».

### Что всплывает и что звучит

Переключатель «авто / вручную» из нынешней озвучки уходит; у Омы свои правила:

- **Пузыри со статусами — всегда.** Статусы активного агента — по ходу
  работы; от фоновых агентов — сразу короткие «проект: готово» и «проект:
  вопрос: <текст вопроса>».
- **Голосом статусы звучат только при включённом постоянном диалоге** — это
  режим долгой работы. Без диалога голосом — только срочное (агент ждёт
  разрешения, задал вопрос — как сейчас) и ответы Омы.
- **Тихий режим** глушит весь звук.
- **Чтение по хоткею** («прочитай ход окна в фокусе») остаётся как есть.

### Окно

- По центру экрана, **среднего размера, не на весь экран** (порядка окон todo
  и Jira). Вид — по `~/omarchy-dotfiles/docs/rules.md` §9 и скиллу
  `omarchy-plugin-ui`: `PanelWindow` + `BorderSurface`, без анимации
  открытия, без вкладок.
- **Шапка:** слева значок-орб и «Ома» с подзаголовком-состоянием («Слушаю ·
  4 агента»). Справа по порядку: счётчик крупной цифрой — сколько агентов ждут
  ответа; кнопки-значки: **микрофон** (нажатие — Ома слушает, как ЛКМ по
  орбу), новый чат, история чатов, шестерёнка; у края — тумблер
  **постоянного диалога**.
- **Слева — агенты**, по строке на каждого: точка состояния (работает / ждёт
  ответа / готово / простаивает), проект, что делает сейчас (последний статус
  или вопрос), давность.
- **Справа — текущий чат с Омой**, внизу поле ввода (без своей кнопки
  микрофона — она в шапке).
- **ЛКМ или Enter по агенту** — справа открывается его чат: лента статусов
  агента и разговор с Омой про этот проект в одной переписке. Esc — назад к
  общему чату. Больше ничего — перехода в терминал нет.
- Настройки — за шестерёнкой (rules.md §9, п. 4).

### Постоянный диалог

Тумблер в шапке окна и горячая клавиша. Пока включён — Ома слушает всё время,
без кликов и «Отправить», её можно перебить голосом (как сейчас
`agent_voice`). Статусы агентов в это время **звучат** (сейчас в голосовом
режиме они глушатся) — это и есть сценарий долгой работы.

### Тихий режим

Ничего не звучит: ни статусы, ни ответы. Текст — в пузырях (висят до клика) и
в окне. Включается по расписанию (расписание можно выключить) и вручную.

### Слух и батарея

- **От сети** whisper держится загруженным: от клика до «слушаю» — меньше
  секунды.
- **От батареи** — загрузка по клику: орб показывает «загружаюсь», первая фраза
  ждёт несколько секунд; пока идёт разговор, модель держится и выгружается
  после 5 минут тишины, чтобы видеокарта уснула.

### Что Ома видит

Кроме фразы — конец переписки **любого** агента из сводки (транскрипт; агент
в фокусе — по умолчанию для «это») и текст, выделенный мышью (primary
selection). Снимков экрана нет: экран в облако не
уходит.

## Мои решения (поправимые)

- **Строится в agent-speak.** Демон, синтез, слух (`agent_voice`), хуки и
  транскрипты агентов уже здесь. Плагин `predmaxim.agent-speak` становится
  Омой: значок в баре уходит, его место занимает орб; настройки озвучки
  (статусы, голос, скорость) переезжают на страницу за шестерёнкой; режим
  «авто / вручную» и строка «Разговор» исчезают — их заменяют правила Омы и
  постоянный диалог.
- **Орб — штатный плагин типа `panel`** (постоянное плавающее окно, как OSD,
  `keepLoaded`), слой поверх окон; клики проходят сквозь всё, кроме самого
  кружка и пузыря. Никаких обходов Omarchy.
- **Орб прячется**, когда в фокусе полноэкранное окно; агент, ждущий ответа,
  в этом случае не показывается (звук-оповещение работает как сейчас).
- **Мозг Омы — отдельная долгоживущая сессия Claude** (Agent SDK, как сейчас
  `agent_voice`). Своя рабочая папка (например `~/.local/share/agent-speak/oma`)
  с инструкцией роли: заместитель, краткость, без markdown вслух. Права — только
  чтение (`plan`) плюс веб-поиск. Codex мозгом не бывает (на бесплатном плане
  не работает).
- **Краткость** — в инструкции роли: ответ в одну-три фразы, без вступлений;
  один и тот же текст звучит и показывается.
- **Реестр агентов — в демоне.** Демон уже получает хуки и читает транскрипты;
  он ведёт по сессии: агент, проект, папка, состояние, последний статус,
  время, ленту последних статусов, текст вопроса, если ждёт. Состояния:
  `UserPromptSubmit` → работает; `MessageDisplay` → новый статус;
  `Notification` → ждёт ответа (текст уже переводится в `notification_text`);
  `Stop` → готово; долго нет событий после `Stop` → простаивает; процесс
  агента завершён → строка уходит. Codex — по rollout-файлу и `notify`.
  Реестр отдаётся плагину через `subscribe`, а Оме — как инструмент
  (например, SDK MCP-инструменты «список агентов» и «лента агента»).
- **Подагенты отсекаются** по тому, что у них свои транскрипты внутри папки
  родительской сессии (проверить на текущей версии Claude Code).
- **Голос статусов в диалоге — по нынешним правилам очередей agent-speak**
  (активное окно по фокусу, финалы неактивных ждут фокуса до 30 минут, срочное
  сразу). Пузыри от этих правил не зависят: текст показывается сразу.
- **Очерёдность звука:** ответ Омы не прерывается статусами; статусы, пришедшие
  во время ответа, встают после него (финалы не теряются, живые статусы могут
  устареть).
- **Пузыри вне тихого режима** гаснут через ~10 секунд после последнего нового
  пузыря (стопка целиком).
- **Ответы Омы звучат всегда, кроме тихого режима** — и на голосовой вопрос, и
  на набранный в окне, в том числе в чатах агентов.
- **Слух — один долгоживущий процесс**; источник питания — по UPower (или
  `/sys/class/power_supply`), смена сети/батареи на лету.
- **Постоянный диалог не слушает чужую речь:** слух ставится на паузу, пока
  идёт запись диктовки voxtype и пока микрофон захвачен другим приложением
  (созвон); орб в это время — «покой».
- **«Что это» без агента в фокусе** — Ома отвечает по фразе и выделению; если
  этого мало — коротко переспрашивает.
- **Чаты хранятся на диске**: у каждого чата своя сессия Claude (продолжение по
  id). Чат агента — один на проект, продолжается при следующем открытии.
- **Расписание тихого режима** по умолчанию 23:00–08:00, меняется в
  настройках.
- **Горячие клавиши:** нынешняя `Super+Ctrl+Alt+S` переключает постоянный
  диалог Омы. Отдельная клавиша «сказать фразу» — на усмотрение строителя.
- **Тексты** — через `tr()` с русской таблицей в `I18n.js`.

## Ограничения

- Порядок работы и вид — `~/omarchy-dotfiles/docs/rules.md` (§9; changelog,
  таблица README, `watch.tsv` при изменениях системы). Только штатные механизмы
  Omarchy, без обёрток и патчей её логики.
- `install.sh` перезапускает сервис и обрывает чтение — спрашивать
  пользователя перед развёртыванием. Перезапуск PipeWire — только всем стеком и
  только с пользователем; `wireplumber` отдельно не перезапускать.
- Проверка интерфейса — снимками (`grim`) и IPC, без вслепую нажатых клавиш;
  не открывать перехватывающие клавиатуру окна, пока пользователь работает,
  не спросив.
- `main` публичный: никаких личных данных в коммитах, ветку `impl` не пушить.
  В коммитах нет ИИ-соавторов.
- Распознавание — локально (whisper large-v3-turbo, CUDA), эхоподавление —
  существующий PipeWire echo-cancel. Встроенный микрофон ноутбука распознаётся
  хуже гарнитуры.
- Авторизация Claude — текущая у CLI (подписка), без отдельных ключей.

## Остаётся строителю

- Структура плагина и id, устройство орба и пузыря в QML, маска ввода.
- Расширение протокола сокета, формат хранения чатов и реестра.
- Как именно Ома получает реестр и ленты (инструменты или контекст к реплике).
- Перенос машины состояний `agent_voice` на клик-фразу и постоянный диалог.
- Начальный размер окна и пузыря.

## Как понять, что готово

- От сети: ЛКМ по орбу → «слушаю» меньше чем за секунду; вопрос → ответ в
  одну-три фразы голосом и в пузыре. От батареи после простоя — «загружаюсь»,
  затем так же.
- Три агента в работе: «Как дела по проектам?» → верное состояние каждого.
- Фоновый агент задал вопрос → орб жёлтый, счётчик в окне 1, пузырь «проект:
  вопрос: …» сразу.
- Пять событий подряд → видны три пузыря, верхний полупрозрачный с переходом.
- Без диалога статусы только в пузырях; с диалогом — ещё и голосом.
- Тихий режим по расписанию → ни звука, пузыри висят до клика.
- Во время диктовки voxtype и созвона диалог не реагирует на речь.
- ПКМ → окно; клик по агенту → его чат; Esc → общий чат; Esc → окно закрыто.
- Постоянный диалог: разговор, перебивание голосом, статусы агентов звучат
  между репликами.
- Значка озвучки в баре нет; строки «Разговор» и режима «авто / вручную» в
  настройках нет.
