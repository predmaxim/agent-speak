# Плагин панели Omarchy для agent-speak

Дата: 2026-10-02. Статус: проект, ждёт одобрения. Основа — `2026-10-02-agent-speak-design.md`.

## Зачем

Управлять озвучкой без правки файлов и без запоминания хоткеев: видеть, говорит ли она сейчас, ставить на паузу, включать и выключать функции — в первую очередь чтение промежуточных статусов, — выбирать голос и скорость.

Критерии успеха:

- по значку в центральной группе видно состояние: говорит / пауза / авто / вручную / сервис не запущен;
- любая настройка меняется в один клик и сразу действует в сервисе;
- голос и скорость можно сравнить на слух прямо из окна.

## Решения, принятые в обсуждении

- Значок — в **центральной группе индикаторов** (клон `predmaxim.indicators`): горит, пока говорит, стоит на паузе или включено «авто»; иначе виден только при наведении на группу.
- Плагин говорит с сервисом **напрямую через его unix-сокет** (`Quickshell.Io` `Socket`): подписка на состояние, команды, изменение настроек.
- Код плагина — в репозитории `agent-speak`, папка `plugin/`; ставит `install.sh` ссылкой в `~/.config/omarchy/plugins/predmaxim.agent-speak` (как `predmaxim.vpn`).
- Клики по значку: **левый** — открыть/закрыть окно; **правый** — пауза/продолжение, если говорит или на паузе, иначе ничего.
- Настройки хранятся в `~/.config/agent-speak/config.toml` сервиса, а не в `shell.json`: это настройки сервиса, он читает их без оболочки. Исключение из `omarchy-dotfiles/docs/rules.md` §9 — записать там.

## Часть 1. Сервис: протокол сокета

Сокет `$XDG_RUNTIME_DIR/agent-speak.sock`, сообщения — JSON-строки (`\n`).

1. **Каждое соединение — в своём потоке.** Команды CLI и хуков — как раньше: одна строка, соединение закрывается.
2. **`{"cmd":"subscribe"}`** — соединение остаётся открытым; сервис сразу пишет полное состояние одной строкой и затем новую строку при каждом изменении:
   ```json
   {"running":true,"speaking":true,"paused":false,"mode":"auto","read_intermediate":true,"speaker":"xenia","rate":"medium","project":"agent-speak"}
   ```
   `project` — имя папки проекта сессии, которую сейчас читают (`cwd` сессии; пустая строка, если не читает). По открытому соединению принимаются и остальные команды.
3. **`{"cmd":"set","key":K,"value":V}`** — ключи и допустимые значения: `mode` — `auto`/`manual`; `read_intermediate` — `true`/`false`; `speaker` — `xenia`/`baya`/`kseniya`/`aidar`/`eugene`; `rate` — `x-slow`/`slow`/`medium`/`fast`/`x-fast`. Применить, сохранить `config.toml`, разослать состояние. Неверный ключ или значение — игнорировать, строка в журнал.
4. **`{"cmd":"say","text":T}`** — образец голоса (`Kind::Preview`), через обычную подготовку текста. Если идёт чтение и не пауза — игнорируется (смену голоса слышно в самом чтении). Если тихо — ставится первым и играет сразу. На паузе — тоже первым и играет, очередь остаётся на паузе, прерванное предложение следующее. Новый образец вытесняет прежний (в очереди не больше одного), по возрасту не устаревает.
5. **Когда рассылается состояние:** начало и конец речи, пауза/продолжение, стоп, смена настроек (через `set`, `mode` или правку файла). Длина очереди не рассылается.
6. **Устройство:** поток воспроизведения при смене «говорит/молчит» шлёт событие в основной цикл; цикл собирает состояние и пишет его подписчикам; подписчик, запись которому не удалась, удаляется молча.

## Часть 2. Значок

Скрытый виджет плагина на панели (`visible: false`, ширина 0) держит IPC `omarchy-shell predmaxim.agent-speak toggle` — образец `predmaxim.todo`. Значок — `plugin/Indicator.qml` (`BarIndicator`), хук `patch_indicators` в `omarchy-dotfiles` копирует его в клон индикаторов как `indicators/AgentSpeak.qml`.

| Состояние | Горит | Значок | Подсказка |
|---|---|---|---|
| говорит | да | динамик с волнами | «Читаю: <project>» |
| пауза | да | пауза | «Пауза — правый клик продолжит» |
| авто, тишина | да | динамик | «Авто: агент в фокусе читается сам» |
| вручную, тишина | нет | динамик, приглушённый | «Вручную: Super+Alt+R» |
| сервис недоступен | нет | динамик перечёркнут | «Сервис озвучки не запущен» |

Значки — из того же шрифта, что у соседних индикаторов; размер сверить снимком. Своя подписка на сокет; нет соединения — состояние «недоступен», переподключение раз в 5 с. Надписи — через `I18n.js` плагина.

## Часть 3. Окно настроек

Модалка по центру с затемнением (`PanelWindow` слоя Overlay, `Color.menu.scrim`, карточка `BorderSurface` цвета `Color.popups`) — образец `predmaxim.todo/Panel.qml`; дизайн — как «Дисплей» (`predmaxim.drives/Panel.qml`): одноцветно, `PanelHero`, `PanelSeparator`, подписи капсом.

- Шапка: значок состояния, заголовок «Озвучка», строка состояния (как подсказка значка).
- Кнопки «Пауза»/«Продолжить» и «Стоп» — активны, пока говорит или на паузе.
- Разделы-селекторы (выбранный пункт подсвечен; образец — режим наушников в `predmaxim.audio`):
  - **Режим**: Авто / Вручную → `set mode`;
  - **Промежуточные статусы**: Читать / Только итог → `set read_intermediate`;
  - **Голос**: Xenia, Baya, Kseniya, Aidar, Eugene → `set speaker`, затем `say` «Так звучит этот голос.»;
  - **Скорость**: пять ступеней x-slow … x-fast → `set rate`, затем `say` с той же фразой.
- Показывается то, что подтвердил сервис (следующая строка состояния), а не нажатое — выбор не «прыгает».
- Сервис недоступен — вместо разделов строка «Сервис озвучки не запущен» и команда `systemctl --user start agent-speakd`.
- Закрытие: Esc, клик мимо карточки, повторный левый клик по значку. Своя подписка на сокет, пока окно открыто.

## Часть 4. Тесты и установка

- `cargo test`: сборка JSON состояния; `set` — допустимые применяются и сохраняются, неверные игнорируются; `say`: образец пропускается при чтении, ставится при тишине и на паузе; в очереди один образец, он впереди; подписчик получает состояние сразу и после изменения (пара unix-сокетов); отвалившийся подписчик удаляется.
- `node plugin/test.js`: `Model.js` — из строки состояния получаются значок, «горит», ключ подсказки; сборка сообщений `set`/`pause`/`stop`/`say`; каждый `tr()` есть в `I18n.js`; запрещённые имена свойств (`state`, `left`, … — как тест `predmaxim.vpn`).
- Вживую: снимок панели (`grim`) — значок рядом с соседями в состояниях «говорит», «пауза», «авто»; переключение настройки в окне меняет `config.toml` и значок; выбор голоса — звучит пример.
- `install.sh` ставит ссылку `plugin/` → `~/.config/omarchy/plugins/predmaxim.agent-speak`. В `omarchy-dotfiles`: плагин в `patch_indicators`, скрытый виджет на панели (`omarchy bar put`), исключение в `rules.md` §9, запись в журнал; затем `omarchy restart shell`.

## Вне рамок

Кнопка «Прочитать ответ» (есть Super+Alt+R), длина очереди и список фраз в окне, словарь терминов в окне, настройки сервиса в `shell.json`.
