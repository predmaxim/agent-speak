Собрано 2026-11-11/12: плагины Omarchy (сайт и GitHub), инструменты вокруг ИИ-агентов, свои идеи по транскриптам Омы. Ссылки — в поле «Источник», обращение 2026-11-11.

## Орб

### `orb-peek` Наведение на орб — карточка агентов — польза high, объём S

Навёл курсор на орб — карточка всех агентов, срочные сверху: кто ждёт и о чём, кто завис, кто готов. Без токенов и звука.

```
        ( O )  <- курсор 0,4 с
+-----------------------------------+
| ? Astral.Edo.Frontend     15 мин  |
|   4 вопроса: вид списка, панель   |
| ! omarchy-vpn  завис, не в Orca   |
| ~ agent-speak     работает 6 мин  |
| v dtc-directus      готов, 3 мин  |
+-----------------------------------+
```

Источник: своя (список 3); данные уже есть: link.agents (Link.qml:20), поля из src/agents.rs:34-52

Заметки: Самый частый вопрос к Оме — статус агентов: около 30 из 309 реплик (грубый grep по транскриптам Омы, список 3). Сейчас каждый такой вопрос — ход Sonnet и 10–15 с. PopupWindow подсказки уже есть (Orb.qml:158-186); порядок строк — чистая функция peekRows в Model.js с тестом в plugin/test.js; нужен HoverHandler и на карточке. При agents_voice=false — прежняя подсказка. Строка agents весит 82–164 КБ (анализ): карточке ленты не нужны. Не проверял, как карточка ложится у угла top-right. Вид орба решает пользователь (rules.md §9).

### `orb-satellites` Спутники агентов на ободе орба — польза high, объём M

Вокруг орба по точке на агента, цвет и место закреплены за ним; ждущий пульсирует, клик по точке открывает его чат.

```
      o     *
   ( ( ? ) )   o
      .
 o работает  * ждёт  ! помощь  . готов
```

Источник: https://github.com/macd2/OmarchyAgentOrbStatus (Agent Pulse, MIT); https://github.com/macd2/OmarchyAgentOrb (MIT); https://github.com/Bert0424/omarchy-wisps (слоты цвета и места, MIT) — доступ 2026-11-11; своя (список 3)

Заметки: Слиты «Кольцо агентов» (список 1) и «Спутники» (список 3). Сейчас орб сводит всех в один цвет (Model.js:29-37). Рисовать внутри orbSlot с расширенным slotSize: маска остаётся одним Region-эллипсом (Orb.qml:86-91), попадание — по углу курсора в нынешнем MouseArea; это снимает главный риск оценки L из анализа. Агентов больше 6 — последняя точка «+N». Цвета из palette.json. Наблюдатель macd2 на Node не брать: у Омы свой источник. При agents_voice=false спутников нет. «Созвездие агентов» в анализе отложено до решения пользователя. Не проверял читаемость точек 6–8 px. Токенов 0, перерисовка только при смене состояния.

### `orb-moods` Орб показывает исход без слов — польза high, объём S

Готово — зелёная вспышка и кольцо, пока не заглянешь; 3+ ошибки инструментов — орб никнет; новость, которую Ома не сказала, — одна волна.

```
 готово      беда          новость без слов
 (( O ))     ( o )        (  ( ( O ) )  )

Ошибки считать по is_error в tool_result (транскрипт демон уже читает) или штатным хуком PostToolUseFailure (есть в code.claude.com/docs/en/hooks, проверено 2026-11-11). Кольцо и «беда» снимаются по фокусу терминала агента (focus.rs). У claude-crab лицензии нет — только идея. Анимации короткие, учесть reduceMotion, на батарее не крутить постоянно. orb_over_fullscreen=false — под полноэкранным окном не видно. Вид орба решает пользователь.

### `orb-rim` Обод: дуга возраста ожидания и значки без цифр — польза medium, объём S

Дуга по ободу растёт, пока ждёт самый старый вопрос; значки без цифр: есть непрослушанное, тихий режим, «не сейчас» до HH:MM.

```
   ,-~~-.       ( O ).  точка: непрослушанное
  (  ?   )      ( O )C  луна: тихо
   `-..         ( O )@  часы: «не сейчас»
 дуга: ждёт 9 из 15 мин
```

Источник: https://github.com/Arjun010011/omarchy-dynamic-island (кольцо таймера, MIT) — доступ 2026-11-11; значки — своя (список 3)

Заметки: Слиты «Кольцо ожидания» (2) и «Бейджи на ободе» (3). Полная дуга — через remind_after. Во время разговора луна тихого режима сейчас не видна: orbMode отдаёт quiet последним (Model.js:29-37), и 2026-11-07 мозг выдумал ответ на «А где звук-то?». Цифры «×3» и счётчики на орбе из списка 1 не брать: rules.md:193 — индикатор без цифр, число — в карточке и окне (проверил rules.md:193). Поля held и busy_until — в конец строки статуса. Иконки Lucide (ISC). Вид орба решает пользователь.

### `orb-status-click` Средний клик — сводка одной фразой без мозга — польза high, объём S

Средний клик по орбу — за секунду одна фраза, собранная кодом без мозга: кто работает, кто ждёт и о чём, кто готов.

```
( O ) <- СКМ  =>  «Работают двое. Astral ждёт ответа про ветку.»
```

Источник: своя (список 3); основа — Board::overview, src/news.rs:167-181

Заметки: Пользователь просил «коротко, буквально одним предложением» (2026-10-29T17:56); краткость мозг нарушает примерно в 55 % ответов (анализ). Команда сокета status, фраза из Registry, enqueue Kind::News; Qt.MiddleButton в Orb.qml. Это явный жест, а не разбор слов. rules.md:191 «СКМ не используется» — правило для значков бара; для орба решает пользователь, запасной жест — двойной клик. Список 2 предлагал СКМ = «тихо/звук» (по jburchel/omarchy-jarvis) — конфликт, выбрать одно; «тихо» уже есть на ПКМ по значку. Токенов 0.

### `orb-wheel` Колесо над орбом — темп этого ответа — польза medium, объём S

Ома говорит длинно — крути колесо над орбом: оставшиеся фразы этого ответа звучат быстрее или медленнее, потом темп возвращается.

```
( spk )  колесо вверх -> » fast
         колесо вниз  -> « slow
```

Источник: https://github.com/chalkers/omarchy-read-aloud (0.5–3×, MIT); https://github.com/jburchel/omarchy-jarvis (MIT) — доступ 2026-11-11; своя (список 3)

Заметки: Слиты «Колесо во время речи» (3), «Колесо — громкость, Shift — скорость» (2) и голосовые «быстрее/медленнее» (1). speaker.rs:165 берёт rate на каждую фразу — временный rate до конца поколения (generation, speaker.rs:63); в config.toml не писать. Вне речи колесо может менять громкость только потока Омы. Эффект запаздывает на уже синтезированную фразу; сколько синтезируется впереди, не проверял. Не проверял, доходят ли события колеса до слоя layer-shell с маской Region. Токенов 0.

### `orb-address` Спутник как адресат: удержал — говоришь ему, бросил файл — в его чат — польза medium, объём M

Держишь точку агента — говоришь ему без имени; бросил на неё скриншот или текст — открылся его чат с вложением в поле.

```
 * Astral <- держи: (( mic )) -> «Передать Astral: ...? Скажи: да, передай»
 [shot.png] ~~drag~~> * Astral => окно: чат Astral, поле: /tmp/shot.png |
```

Источник: своя (список 3); https://github.com/GNSB/omarchy-agent-notch (картинки в промпт, MIT) — доступ 2026-11-11

Заметки: Слиты «Удержание спутника», «Перетащи на спутник» (3) и «Перетащи на орб» (2). Зависит от «Спутников». Whisper коверкает имена: «Ajaxpeed Speaker» вместо agent-speak (2026-10-29T18:50), «вам проб» вместо omaprobe. Безопасность не ослабляется: голосом — только отдельной репликой «да, передай» (orders.py:136-141); набранное в окне отправляет Enter самого пользователя, как сейчас. Открыто: съеденное начало фразы при нажатии из покоя. Не проверял Wayland DnD на layer-shell Quickshell и чтение картинки агентом по пути. Картинки в Sonnet дорогие — предупреждать. Черновик длинного голосового поручения с правкой в окне (JamesWeatherhead/jukebox) не включён: польза низкая.


## «Ты тут?» и слух

### `here-eyes-first` «Ты тут?» сначала глазами: огонёк к курсору — польза high, объём M

Есть новости после простоя — огонёк в цвете орба подлетает к курсору; шевельнул мышью — «тут»; голосом спросит, только если не заметил.

```
 0-60 с:  курсор <~ o   огонёк пульсирует, без звука
 потом:   «Эй, ты тут? Есть новости.»
            ,-~~-.
           (  mic )  <- дуга 20 с убывает
```

Источник: https://github.com/Bert0424/omarchy-wisps (огонёк к курсору, MIT); https://github.com/wbuf81/omarchy-idle-screencounter (пассивный слой без ввода, MIT) — доступ 2026-11-11; своя (список 3)

Заметки: Слиты «огонёк к курсору» (1) и «сначала глазами, потом голосом» (3). Проверил (список 3, journalctl с 2026-10-25): 21 «Эй, ты тут?»; анализ: 57 % без отклика в первом проходе, через динамики ответ в первые 3 с выбрасывается как эхо. Ответ движением мыши уже засчитывается (README). Курсор — штатный hyprctl cursorpos, ввод — от predmaxim.presence, решает демон (daemon.rs:1136-1146, here_ask). Огонёк — отдельный PanelWindow без области ввода. Фразу daemon.rs:79 выбрал пользователь, она остаётся. Причину «не слышит» не устраняет — нужен отдельный разбор бага. Присутствие по взгляду (glanced) не включено: PAM-разблокировка лицом и камера на батарее.

### `ear-meter` Орб слышит: пик микрофона, mic-off, дуга слушания — польза high, объём S

Орб прыгает в такт твоему голосу, пока Ома слушает: неподвижен — звук до неё не доходит; вход выключен — перечёркнутый микрофон.

```
 звук идёт      звука нет      вход выключен
 ((( mic )))     ( mic )         ( mic/ )
 диск прыгает   неподвижен      серый, «Ты тут?» не звучит
 дуга по ободу — сколько ещё слушает
```

Источник: своя (список 3); стоковый PwNodePeakMonitor — /usr/lib/qt6/qml/Quickshell/Services/Pipewire/quickshell-service-pipewire.qmltypes:514-575 (quickshell 0.3.2, проверено 2026-11-11)

Заметки: Слиты «Ухо-метр», «Дуга: сколько ещё слушает» и «Волна её голоса» (все из списка 3). Пример: 2026-10-25T14:41 «ты в наушниках меня не слышишь». Узел oma-ear (context.py:76, ear.py:17), монитор включён только в listening. Mute Ома сейчас не проверяет (grep -i mute находит только Mutex). Дуга — новое поле listen_until в строке статуса, вместе поправить OFFLINE в Model.js и link.py. Тот же приём в speaking: pw-cat с node.name=oma-voice (audio.rs:22) — волна её голоса, видно, дошёл ли звук до PipeWire (случай 2026-11-07 «А где звук-то?»). Не проверял: пик с потока, а не устройства; цену CPU; имя свойства mute. Показывает, где рвётся цепочка, но баг «не слышит» не чинит.

### `headset-button` Кнопка наушников — пульт Омы — польза medium, объём M

Пока Ома говорит или спрашивает «Ты тут?», кнопка на наушнике значит «я тут» или «замолчи», а next — сводку кодом.

Источник: https://specifications.freedesktop.org/mpris/latest/Player_Interface.html (доступ 2026-11-11); своя (список 3)

Заметки: Демон регистрирует MPRIS-плеер org.mpris.MediaPlayer2.oma (zbus) только на время речи или вопроса; PlayPause и Next — команды сокета. Голос через Bluetooth-гарнитуру хрупок (rules.md), а кнопка работает и в режиме музыки. Риск: оболочка шлёт playPause самому старому играющему плееру (проверил, список 3: /usr/share/omarchy/shell/plugins/services/media/Service.qml:202-203) — при играющей музыке кнопка достанется ей. Перехватывать бинд оболочки — костыль (признак 1), не делать. Не проверял, сбрасывает ли нажатие счётчик простоя.

### `music-pause` Музыка на паузе, пока Ома говорит и слушает — польза medium, объём S

Пока Ома говорит или ждёт ответа, играющая музыка встаёт на паузу, потом продолжается — только та, что играла.

Источник: https://github.com/goodroot/hyprwhspr (ducking, MIT); https://github.com/jburchel/omarchy-meeting-mode (возвращает только своё, MIT); https://specifications.freedesktop.org/mpris/latest/ — доступ 2026-11-11

Заметки: Гипотеза, не проверял: музыка заглушает и голос Омы, и ответ для whisper. Меняет прежнее решение (README: под музыку Ома говорит) — решает пользователь. Вариант Б (S): пауза MPRIS через Quickshell.Services.Mpris в плагине — документированный путь; playerctl не установлен (проверено pacman, список 2). Вариант А (M): duck-level WirePlumber по ролям (/usr/share/wireplumber/wireplumber.conf:1013, 0.5.18) требует перезапуска всего звукового стека — риск для звука, только с явного согласия; wireplumber отдельно не перезапускать.

### `wake-word` Слово-побудка «Ома» — польза medium, объём L

«Ома, …» с другого конца комнаты начинает разговор без клика, а «Ома, тут» отвечает на «Ты тут?».

Источник: https://github.com/jburchel/omarchy-jarvis (openWakeWord, ~3 % CPU, MIT); https://github.com/dscripka/openWakeWord (код Apache-2.0, модели CC BY-NC-SA 4.0); https://github.com/alphacep/vosk-api (Apache-2.0); https://github.com/orbe-project/orbe-desktop (лицензии нет) — доступ 2026-11-11

Заметки: Детектор за адаптером в python/agent_voice/ear.py: Vosk с грамматикой [ома, [unk]] и малой русской моделью или своя модель openWakeWord (готовые — CC BY-NC-SA, проверил README, список 2). Срабатывание идёт тем же путём, что клик. Батарея: микрофон и CPU постоянно — только от сети или в наушниках, с выключателем. Ложные срабатывания от её речи гасить нынешним эхоподавлением. CPU Vosk на этой машине не мерил.


## Внимание и агенты

### `reminder-ladder` Напоминания лестницей и починка пустого «ждёт ответа:» — польза high, объём S

Первое напоминание — голосом с сутью вопроса, второе — «Astral ждёт», дальше только цвет; пустая фраза «… всё ещё ждёт ответа:» исчезнет.

Источник: своя (список 3); https://github.com/CallMeBakugo/omarchy-hermes-attention (повторы складываются, замолкает через 30 мин, MIT) — доступ 2026-11-11

Заметки: Баг-фикс, делать первым. Проверил (список 3): journalctl --user -u agent-speakd --since 2026-10-25 — 18 из 149 фраз «… всё ещё ждёт ответа:» с пустым хвостом (10 Astral.Edo.Frontend, 8 omaprobe); причина — src/watch.rs:347, format! при пустом status. Анализ: «ждёт ответа» прозвучало 29 раз, до 12 на сессию без предела. Правка: счётчик в Track рядом с reminded, текст из ask (agents.rs:52), без двоеточия при пустом; remind_voice_max в config.rs и SETTINGS_ROWS. Повтор показывать не цифрой «×3» на орбе (rules.md:193), а пульсом спутника. Токенов 0.

### `lanes` Три полосы СЕЙЧАС / ДАЛЬШЕ / ФОН и бюджет речи — польза high, объём M

Голосом сразу — только то, что держит работу; готовые итоги копятся и звучат одной фразой не чаще раза в N минут; промежуточное — только в окне.

```
+ СЕЙЧАС ---------------------------+
| ? Astral   вопрос про ветку   4м  |
+ ДАЛЬШЕ ---------------------------+
| v datebook     готов  [C разобрано]|
| v agent-speak  готов              |
+ ФОН (свёрнуто) -------------------+
```

Источник: https://github.com/tomismeta/omarchy-aperture (NOW/NEXT/AMBIENT, MIT); https://github.com/nblanchard-intact/omarchy-laya-attention (MIT); https://github.com/jeremylongshore/omarchy-crew-chief-entry (MIT); https://github.com/aigorahub/herdr-lantern (MIT); https://github.com/eliasstravik/shepherdr (MIT); https://github.com/PSthelyBlog/omarchy-hermes-companion (min_gap 300 / urgent_gap 60 / max_per_hour 8, MIT) — доступ 2026-11-11; своя (список 3)

Заметки: Слиты «Три яруса» (1), «Три полосы» (2), «Бюджет непрошеной речи» (1), «Голосовой бюджет» (3). Анализ: 96 из 98 новостных фраз про один проект; только 34 из 167 интервалов короче 2 мин — склейка без бюджета почти ничего не даёт. queue.rs уже различает вопрос, итог, промежуточное; Board::take склеивает Final, больше трёх — сводкой (SUMMARY_OVER=3). ДАЛЬШЕ сливается кодом из имён и счёта, Haiku — только для одного важного итога; ФОН модель не пересказывает. Клавиша C «разобрано» агенту ничего не шлёт. Подтверждения поручений под бюджет не попадают. Классификатор Laya не брать (0,85–1,5 ГБ, английский). Бюджет меняет утверждённый формат «конец хода — одной-двумя фразами» (спека 2026-10-24) — нужно «да» пользователя. Токенов меньше.
