# agent-speak

Озвучка ИИ-агентов (Claude Code, Codex) по ходу работы: промежуточные статусы и ответы звучат сразу, по-русски, голосом Silero. Текст готовится к чтению без ИИ на пути к звуку: код и markdown выбрасываются, пути — имя файла, числа — словами, английские термины — по словарю.

## Как это звучит

- **Авто** — агент читается сам по ходу работы. **Вручную** — по хоткею читается весь последний ход окна в фокусе.
- **Окна по фокусу.** Говорит одно, «активное» окно агента. Оно меняется, только если фокус пробыл на другом окне агента 5 секунд; браузер, всплывающие окна и прочее не в счёт. При смене фокуса текущее предложение договаривается, затем звучит новое окно; вернулся — старое продолжается с того же места.
- **Статусы — только вживую.** Промежуточные статусы неактивных окон выбрасываются. **Конечные ответы** неактивных окон ждут в своей очереди (до 30 минут) и звучат, когда окно станет активным. В конце хода ответ сверяется с тем, что уже прозвучало: пропущенное встаёт на своё место, прозвучавшее не повторяется. Начатое сообщение дочитывается до конца.
- **Ручное чтение закреплено:** дочитывается, даже если фокус ушёл в другое окно; статусы в это время не вклиниваются.
- **Отправка сообщения агенту чтение не обрывает:** ответ дочитывается, выбрасываются только не начатые статусы прошлого хода.
- **Свой голос у каждого окна.** Первое заговорившее окно — голос из настроек, следующие — Baya, Kseniya, Aidar, Eugene (по кругу). Голоса держатся до перезапуска сервиса.
- **Срочное** («нужно разрешение», «агент ждёт ответа») из любого окна звучит сразу, с названием проекта.

## Управление

| Что | Как |
|---|---|
| Прочитать ход окна в фокусе / остановить | `agent-speak read` (хоткей Super+Alt+R) |
| Авто ↔ вручную | `agent-speak mode` (Super+Alt+Shift+R) |
| Пауза / продолжить (с начала предложения) | `agent-speak pause` (Super+Alt+P), правый клик по значку |
| Стоп | `agent-speak stop` (Home — диктовка — тоже останавливает) |
| Настройки | окно плагина — левый клик по значку |

Хоткеи задаются в Hyprland (у автора — `omarchy-dotfiles`, `hyprland.lua`).

**Плагин панели Omarchy** `predmaxim.agent-speak` (`plugin/`): значок в центральной группе индикаторов горит, пока говорит, на паузе или включено «авто»; подсказка — что и откуда читается. Окно настроек: режим, промежуточные статусы (читать / только итог), голос и скорость (пример голоса звучит, только когда ничего не читается), пауза и стоп. Плагин говорит с сервисом через его сокет.

Уведомления — только о том, чего не видно на значке: «Нечего читать», «В фокусе нет агента», «Синтез упал».

## Настройки

`~/.config/agent-speak/config.toml` (сервис перечитывает файл сам; удобнее — окном плагина):

| Ключ | Значения | По умолчанию |
|---|---|---|
| `mode` | `auto` / `manual` | `manual` |
| `read_intermediate` | `true` / `false` (только итог хода) | `true` |
| `speaker` | `xenia`, `baya`, `kseniya`, `aidar`, `eugene` | `xenia` |
| `rate` | `x-slow` … `x-fast` | `medium` |
| `max_age_secs` | сколько живёт не начатый статус | `30` |

Словарь произношений — `~/.local/share/agent-speak/terms.tsv` (`слово<TAB>произношение`, `+` — ударение). Незнакомые слова сначала читаются транслитерацией, а фоновая самая лёгкая модель агента (Haiku / быстрая модель Codex) дописывает их в словарь.

## Устройство

- `agent-speakd` — сервис на Rust (`systemctl --user status agent-speakd`; журнал `journalctl --user -u agent-speakd` — каждое чтение, переключение окна и пропущенная фраза с причиной).
- Источники: Claude — хук `MessageDisplay` по ходу работы, `Stop` — конец хода, `UserPromptSubmit`, `Notification`; транскрипт — для ручного чтения. Codex — rollout-файл и `notify`.
- `python/silero_tts.py` — синтез Silero, модель держится в памяти.
- Сокет `$XDG_RUNTIME_DIR/agent-speak.sock`, JSON-строки: `subscribe` (состояние и его изменения), `set`, `say`, `read`, `stop`, `pause`, `mode`; хуки — `agent-speak hook <вид>`.

## Установка и тесты

`./install.sh` — сборка, сервис `systemd --user`, venv с Silero, ссылка на плагин. Хуки Claude (`~/.claude/settings.json`: `Stop`, `UserPromptSubmit`, `Notification`, `MessageDisplay` → `agent-speak hook <вид>`) и `notify` Codex (`~/.codex/config.toml`) подключаются вручную.

Тесты: `cargo test`, с моделью — `cargo test -- --ignored` и `python/test_silero_tts.py`; плагин — `node plugin/test.js`.

Проекты: `docs/superpowers/specs/`.
